# Data

The data is not included in this repository. Download it from the competition page:

**[Richter's Predictor: Modeling Earthquake Damage](https://www.drivendata.org/competitions/57/nepal-earthquake/data/)** (DrivenData, 2015 Gorkha earthquake, Nepal)

Place these files in this folder:

```text
data/train_values.csv
data/train_labels.csv
data/test_values.csv
```

`submission_format.csv` from the same page is optional (output format reference).
